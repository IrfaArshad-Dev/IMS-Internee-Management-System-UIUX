# IMS – Internee Management System (UI/UX Design)

A complete UI/UX design for a platform that helps organizations manage
interns end-to-end — from onboarding to offboarding.

**Role:** UI/UX Designer (Team project — 4 members)
**Tools:** Figma
**Project:** Internship Project 1

## Overview
IMS centralizes internship management: attendance tracking, task
management, a learning portal, performance analytics, team communication,
and a certification system — all in one dashboard.

## Modules Designed
1. **Onboarding & Authentication** — splash, login, signup, OTP verification, password reset
2. **Dashboard** — attendance %, task summary, progress overview, activity feed
3. **Tasks** — task list, filtering, submission flow, status tracking
4. **Attendance** — calendar-based marking, history, leave requests, export
5. **Learning Center** — resources, training sessions, recorded material, certificates
6. **Communication** — announcements, messaging, discussion board, notifications
7. **Performance** — score tracking, feedback, badges, evaluations
8. **Profile & Settings** — personal info, skills, resume, portfolio, appearance
9. **Offboarding** — exit checklist, certificate request, feedback, completion summary

## Screens
All 79 screens are organized under `/screens`, sorted into 9 module folders. Each folder's README lists what's inside in order (e.g. `03-tasks/06-task-details.jpg`).
